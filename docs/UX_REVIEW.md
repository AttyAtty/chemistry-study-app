# Chemica UX改善・確認結果

本番デプロイ、ドメイン接続、Supabase管理画面の変更は行っていません。

## 実装した内容

| 対象 | 対応 |
| --- | --- |
| 酸化数問題 | 表の対象元素を問題文に明示。対象が不明な問題は生成しない。KMnO₄はMnを指定。 |
| 検索・直接リンク | 折りたたみの親を展開し、描画後に移動・一時強調。同一ページ移動にも対応。 |
| タイトル・導線 | ブランド重複を解消。「問題演習」「印刷小テスト」に統一。単元入口と目次を整理。 |
| 共有・一覧 | 共有をその他メニューとフッターへ移動。一覧は/home#fieldsに統一し位置を保持。 |
| 系統図・表 | 詳細設定を折りたたみ、拡大・全画面操作を案内。スマホの表は先頭列固定と横スクロール案内。 |
| 可読性 | 本文・副ボタンの色、見出し、狭い画面での配置を改善。 |
| ホーム・記録 | 初回と継続利用を分岐。復習0件の次の学習、未受験表示、集計範囲、70%以上の進捗基準を明示。 |
| 保存・認証 | ログイン入口と保存状態を表示。コードの送信先、再送、メール変更、エラー、元ページ復帰を改善。 |
| データ設定 | アカウント・バックアップ・復元・更新を整理。既存の検証、確認、保護アーカイブを維持。 |
| PWA・移行 | 追加操作と端末別手順、アプリ表示での非表示、案内抑制を実装。manifestの起動先を/homeに変更。 |
| 印刷小テスト | 分野・範囲・問題数を選択。解答を折りたたみ、印刷時のみ展開。「問題を作り直す」に変更。 |
| 演習 | 集中表示、中断・再開・終了を追加。回答履歴と完了時の集計を区別し、再開で二重記録しない。 |
| 電気分解 | 選択条件に応じた入力例を表示し、自己採点用であることを明示。 |

## 確認結果

- `npm run build`、`npm run lint`、`npm run typecheck`：成功。
- 保存系テスト：35件、phase2：25件、phase4：19件、PWA単体：15件、教材確認：3件すべて成功。
- Chromeブラウザテスト：20件すべて成功。PC幅1280px、スマホ幅390pxで検索・直接URL・同一ページリンク、折りたたみ、一覧位置、回答・中断・再開・記録、空状態、印刷、認証、オフラインを確認。
- 320px・390px・1280pxのホーム、設定、単元、系統図を画像確認。ページ全体の横はみ出し、実行時エラーなし。
- 既存学習データのスキーマは変更していません。保護・復元・所有者判定の回帰テストも成功しました。

## 未対応・外部確認

- 実機のiPhone/Androidでのインストール、実際のメール配送と本番クラウド保存は未検証。認証・インストールのブラウザ検証はモックを使用しています。
- 既存実装には複数端末のデータ統合、クラウドからの移行用ダウンロード、独立した最終保存時刻がありません。対応済みと表示せず、ドメイン移行はJSONバックアップ・復元を案内します。
- chemica.appは候補です。取得、DNS、Vercel接続、Supabase認証URL設定は外部作業です。[設定と移行手順](DOMAIN_MIGRATION.md)に具体的な手順を記載しています。旧サイトの強制転送は追加していません。
