# Reaction Map レイアウト改善

## 実装

React Flow / Dagre / ELKは使用していない。既存の`src/lib/reactionLayout.ts`によるグラフ距離ベースの独自配置とSVG直交経路を拡張した。化学データのファイルは変更していない。

- PC: 楕円配置の基準半径を横430→520、縦205→280へ拡大。物質間の分離余白を56→88へ変更。
- Mobile: 従来の階層・2列配置を維持。列間270→320、行間190→250、分離余白38→64へ変更。切り替えは従来どおり図の表示領域が640px未満の場合。
- 物質名・化学式・色の注記・芳香族構造から表示寸法を決め、配置計算とDOMで共有。化学式の途中改行を防止。
- ラベルは見出し・区分・条件・注記を別行として寸法を予約。旧実装の高さ112px上限を撤廃。
- 矢印をすべて確定した後、全物質・全矢印・配置済みラベルを避けて反応ラベルを配置。長いラベルを優先し、各線分近傍から探索を広げる。
- 矢印は4辺の接続位置と障害物の外側の迂回線を候補にする。物質通過を最優先で避け、経路長と既存矢印との共有区間を評価する。
- 共通設定`REACTION_SPACING`: 外周64、物質クリアランス24、ラベル間16、矢印クリアランス12、接続余白14、迂回レーン間20、ラベル最大幅248px。
- 図・矢印・ラベルすべての外接矩形を正規化してからfitを計算。全体表示を維持。初期表示は文字の可読性を優先し80%を下限として中心付近を表示するため、大きい図では内部スクロールが必要。
- 表示領域に`min-width:0`と幅制約を設定し、操作ボタンを折り返す。拡大中の配置編集は表示倍率を座標換算に反映。
- 個別座標overrideの追加はない。既存の有機系の`centerNode`と未使用の`canvas`メタデータは維持。現行データに`zones`指定はない。

## 検証

`node scripts/audit-reaction-layout.mjs`で19系×PC/Mobileの38配置を検証した。結果は`reaction-layout-audit.json`。変更前比較は実行時のGit HEADを用いる。寸法と直交線分による幾何検査であり、ブラウザーの実測検査ではない。

| 計算上の重なり | 変更前 | 変更後 |
| --- | ---: | ---: |
| node–node | 0 | 0 |
| node–label | 132 | 0 |
| label–label | 83 | 0 |
| edge線分–label | 1416 | 0 |
| edge線分–無関係なnode | 327 | 0 |
| 別edgeの同一直線上の重複線分ペア | 515 | 83 |

有機: トルエン、フェノール、ホルムアルデヒド・ギ酸、エチレン、エタノール、ベンゼン、アセチレン、アニリン。

無機: Ca、Fe、N、Na、P、Si、S、Sn、塩素・次亜塩素酸、Mn、Cr。

空グラフと自己ループも検証。変更したTypeScriptファイルのESLint検査成功。`npm run build`はサンドボックスで子プロセス生成がEPERMとなったが、通常権限で成功した。

## 未確認事項・制約

- ブラウザー接続が利用できず、1920×1080、1440×900、1366×768、768px、430px、390px、375px、320pxの実画面検証は未実施。DOMの実際のフォント寸法、横スクロールの有無、zoom/pan操作の目視確認は残る。
- 矢印同士の交差・共有部分は完全には解消していない。幾何検査の線分には矢尻の描画面積を含まない。
- 混雑箇所ではラベルが矢印から離れることがある。大きい図の全体表示では文字が小さくなるため、読みやすい倍率との切り替えが必要。
- 配置編集でユーザーが物質を重ねた場合の自動再配置は行わない。
- 大規模な有機系では配置計算に時間がかかる。ズームなどの操作で再計算しないようメモ化している。
- 印刷の実ページ確認は未実施。
