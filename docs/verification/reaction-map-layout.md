# Reaction Map レイアウト改善（2026-09-12 追加調整）

## 実装と変更範囲

作業先: `C:/Web_App_Original/chemistry-study-app`。
前回の改善は `c16f972` にコミット済み。今回はその共通実装を改善した。
React Flow / Dagre / ELK は不使用。`ReactionMapStudio.tsx` が共通のグラフと表示寸法を生成し、`src/lib/reactionLayout.ts` がグラフ距離による配置・衝突分離・SVG直交経路・ラベル配置を担当する。
PC は中心物質からの距離に応じた楕円配置、Mobile は階層ごとの最大2列配置。単純な鎖はPC横方向、Mobile縦方向。表示領域640px未満でMobileへ切り替える。

化学データ、物質名、化学式、反応条件、ID、色の意味、文字サイズは変更していない。個別座標overrideの追加はない。既存の有機系 `centerNode` と未使用 `canvas` メタデータは維持。現行データに `zones` 指定はない。別実装やレイアウトライブラリは追加していない。

## 密集の原因と改善

前回、ラベル寸法の過小評価、後続矢印を考慮しないラベル配置、狭い物質間隔を改善済み。今回残っていた原因は、矢印がグローバルな反応番号で3種類の接続位置を使い回す点と、ラベル探索が最初の線分を優先し短い折れ曲がり付近にも配置する点。

- 物質ごとに接続反応を列挙し、各反応に別の接続位置を割り当てる。端の余白を残し、反応数に応じて接続間隔を調節する。
- ラベルは長い線分と経路中央に近い位置を優先。全物質・全矢印・配置済みラベルを避ける既存処理は維持する。
- ラベル間・物質周囲・矢印周囲の余白を増やす。
- 1440px以上の画面ではReaction Mapを含むページの最大幅を1240から1600pxに拡大。1366px以下には適用しない。
