# 系統分離・系統分析 Phase A

## 既存構成との接続
- 教材は `src/data/chemistry.ts` と分野別TypeScriptデータ、単元ページは `src/app/units/[slug]/page.tsx` で構成。
- 既存の芳香族構造式・反応マップもReact/SVGを使用。新機能は独立したデータ・描画コンポーネントとして追加。
- テーマは既存の `--surface`・`--text`・`--muted` 等を使用。既存アプリにダークモード切替はないため、新しい独自テーマは導入しない。
- 2ページを静的生成し、既存postbuildのプリレンダーマニフェストからオフライン保存する。外部データ取得や画像は不要。

## データと拡張
`types.ts` は Diagram / SeparationNode / SeparationEdge / Group / Reagent / Condition / Layer / Note を定義。
ノードは表示名、化学式、種類、本文、補足、沈殿色、層、座標を持つ。辺は接続先、試薬、条件、補足を持つ。
安定したIDとblankableをノード・辺・試薬・条件ごとに持たせる。Phase Bでは図データを変更せず、表示用のマスク（対象IDとフィールドの集合）を渡す。
物質のみ・試薬のみは対象フィールドで選別し、ランダム出題はseedつきの選択処理を別モジュールに追加できる。
答えの照合には表示文字列を使わずIDと対象フィールドを使う。印刷時も同じデータとSVGを再利用できる。
現在の座標・ノード寸法は図データ側で管理。長い名称や新ノード追加時は配置調整が必要。

## 受験参考書型レイアウトへの修正
- 上部は横長の混合物枠。右のろ液／エーテル層を主幹とし、各段階の沈殿／水層を左へ分岐させる。
- 無機は属・沈殿式・色を小さな枠に集約。有機の水層からの遊離物は水層の直下へ配置する。
- 試薬と短い条件を分岐直前に置き、回収操作は回収先へ向かう縦線に添える。線はすべて縦・横。
- 既存ノード・辺・試薬・条件のID、blankable、化学式、詳細説明、接続関係を維持。
- 任意の `node.display`（短い見出し・本文・注記）と `edge.display`（折れ線座標・ラベル制御）を追加。図データ末尾の2テンプレートで配置する。
- 画面のSVG要素にも `data-node-id` / `data-edge-id` / `data-field-id` を付け、穴埋めのマスク対象を元データに対応させる。印刷も同じSVGと固定座標を利用可能。
- 詳細モードは図の下の説明を切り替える。基本図の寸法・配置を動かさない。
- PCは中央表示、スマホは1000px幅を保って図枠内で横スクロール。拡大表示も維持。
- 添付画像は実行環境で確認できなかったため、ユーザーが列挙した参考図の特徴に基づいて配置した。

## 化学上の範囲
無機は指定10種に限定。沈殿後はろ別する。酸性H₂Sによる鉄(III)の還元を注記し、H₂S除去・再酸化を次段階の条件とする。
第3段階はNH₄Cl＋過剰NH₃水で亜鉛をアンミン錯体として残す。実際の溶解度・pH・濃度の定量モデルは扱わない。
有機はHCl → NaHCO₃ → NaOHの順で抽出し、水層の塩から3物質を遊離する。再抽出・乾燥・溶媒除去は詳細で説明。
中性2物質の分離操作は模式図の対象外とし、蒸留を補足する。
